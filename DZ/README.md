### Часть 1: Реализация алгоритмических функций по теме системы

В соответствии с заданием, в сетевую и сервисную структуру приложения интегрированы два алгоритма, адаптированных под предметную область космической станции:

#### 1. Алгоритм поиска максимальной непрерывной последовательности стабильной работы систем

Функция анализирует телеметрическую строку (состоящую из `0` и `1`), где `1` означает штатную работу систем регенерации («Аква-Ресурс» / «Атмосфера-М»), а `0` — сбой. Используется цикл со строго заданной логикой без явного инкрементируемого счетчика шага для вычисления максимального периода аптайма.

```javascript
function findMaxOnesSequence(telemetryStream) {
    if (!telemetryStream || !/^[01]+$/.test(telemetryStream)) {
        console.log("Ошибка: телеметрия должна содержать только коды 0 и 1");
        return 0;
    }

    let maxStablePeriod = 0;
    let currentStablePeriod = 0;

    // Циклическая обработка потока данных
    for (let i = 0; i < telemetryStream.length; i++) {
        if (telemetryStream[i] === "1") {
            currentStablePeriod++;
            if (currentStablePeriod > maxStablePeriod) {
                maxStablePeriod = currentStablePeriod;
            }
        } else {
            currentStablePeriod = 0; // Сброс при обнаружении сбоя (0)
        }
    }
    return maxStablePeriod;
}
```

#### 2. Рекурсивное выравнивание структуры вложенных логов модулей (flatten)

При сборе данных со смежных узлов жизнеобеспечения, структура логов получается древовидной и глубоко вложенной. Функция flatternArray преобразует многомерную коллекцию (массив) в линейный вид для последовательного анализа ядром СУБД.

```JavaScript
function flatternArray(nestedTelemetryLogs) {
    let plainLogsList = [];

    for (let i = 0; i < nestedTelemetryLogs.length; i++) {
        if (Array.isArray(nestedTelemetryLogs[i])) {
            // Рекурсивный вызов для вложенных массивов логов
            plainLogsList = plainLogsList.concat(flatternArray(nestedTelemetryLogs[i]));
        } else {
            plainLogsList.push(nestedTelemetryLogs[i]);
        }
    }
    return plainLogsList;
}
```

#### 2. Загрузка 3D-модели (GLTFLoader) и автоматическое центрирование

Поскольку скачанные .glb модели могут иметь смещенный центр тяжести (Pivot Point) или некорректный масштаб, в коде реализован алгоритм автоматического выравнивания на основе ограничивающего контейнера (THREE.Box3):

```JavaScript
const loader = new GLTFLoader();
loader.load(
    this.modelPath,
    (gltf) => {
        this.model = gltf.scene;

        // Расчет габаритов и центра модели для автоматического выравнивания
        const box = new THREE.Box3().setFromObject(this.model);
        const center = new THREE.Vector3();
        box.getCenter(center);
        const min = box.min;

        // Смещение геометрии: центрируем по X и Z, ставим основанием на виртуальный пол по Y
        this.model.position.x = -center.x;
        this.model.position.z = -center.z;
        this.model.position.y = -min.y;

        this.scene.add(this.model);

        // Корректировка фокуса камеры и контроллера под габариты объекта
        setTimeout(() => {
            this.camera.position.set(3, 2, 4);
            this.controls.target.set(0, 1, 0);
            this.controls.update();
        }, 100);
    },
    (xhr) => { /* Индикация прогресса загрузки в % */ },
    (error) => { console.error("Ошибка загрузки модели:", error); }
);
```

#### 3. Настройка освещения и интерактивного управления

Для придачи сцене объемности используется комбинированное освещение:

AmbientLight (рассеянный свет, 0x404040) для подсветки неосвещенных зон.

DirectionalLight (направленный свет, 0xffffff, интенсивность 3.0) для имитации солнечного излучения в космосе.

Интерактивное взаимодействие (вращение модели мышью, масштабирование колесиком) реализовано за счет класса OrbitControls. Непрерывный рендеринг и обновление контроллеров завязаны на стандартный браузерный цикл анимации через requestAnimationFrame:

```JavaScript
animate() {
    requestAnimationFrame(() => this.animate());
    if (this.controls) {
        this.controls.update(); // Обновление трекинга мыши
    }
    if (this.renderer && this.scene && this.camera) {
        this.renderer.render(this.scene, this.camera); // Отрисовка кадра
    }
}
```
